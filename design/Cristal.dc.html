CRISTAL: QUÉ SE PUEDE DE VERDAD EN WPF
El «liquid glass» que se ve en la web se hace con backdrop-filter más un feDisplacementMap de SVG para simular refracción. Nada de eso existe en WPF, y meter un WebView para conseguirlo contradice todo el proyecto. Pero Windows ya trae el efecto de fábrica.
Mica DWMSBT_MAINWINDOW = 2
Muestrea el fondo de escritorio una sola vez y lo tiñe. Baratísimo. Pensado para la capa de fondo de una app que vive abierta.
No sirve aquí: el popup aparece sobre lo que sea que tengas abierto, no sobre el wallpaper.
Acrylic ← el nuestro DWMSBT_TRANSIENTWINDOW = 3
Desenfoca en tiempo real lo que hay detrás. Microsoft dice que se use solo en superficies transitorias que se cierran al perder el foco: menús, flyouts.
Tu popup es exactamente eso: ya se oculta en Window_Deactivated. Es el caso de uso que la guía describe.
EL ESTORBO
Hoy DashboardWindow.xaml lleva AllowsTransparency="True" para poder redondear las esquinas. Esa bandera es incompatible con los backdrops del DWM: mientras esté puesta, no hay Acrylic posible.
El cambio es quitarla y pedirle las esquinas al propio Windows, que además las dibuja mejor:
// esquinas redondeadas nativas
DwmSetWindowAttribute(hwnd, 33, 2, 4); // CORNER_PREFERENCE = ROUND
// cristal
DwmSetWindowAttribute(hwnd, 38, 3, 4); // SYSTEMBACKDROP = ACRYLIC
